# Bootstrap asset and XML generation
Scope: GPT-03 preparation. No final material or motion claim.
Inputs: design-system/tokens/bootstrap.json (schema 1), design-system/templates/bootstrap.xml.tmpl, assets/source/bootstrap/preview.png (original preview, Git blob d073ea432797ca9e83a8ea2654de3c9f6440f41b). Outputs: apps/watchface/src/main/res/raw/watchface.xml, apps/watchface/src/main/res/drawable-nodpi/preview.png, assets/generated/bootstrap/palette.svg (host-only reference). Source preview is not a runtime screenshot. The XML template reproduces the earlier face exactly at the original tokens. The palette is generated from sorted token names; SVG is not packaged.
Use Python 3.12 (CI), standard library only. Run `python tools/generate_bootstrap.py --write` to regenerate. Run `python tools/generate_bootstrap.py --check` to compare all committed outputs, repeat generation, and print the deterministic JSON hash manifest. CI rejects stale or absent outputs before building. Review manifest output in the CI log. No timestamps or absolute paths in the manifest. Paths are fixed; symlinks are rejected. The command does not remove unrelated files. Explicit source-set overrides remain separately validated by profile_contract and check_apk; this initial generator manages only the common face. PNG is preserved as source bytes, not regenerated from vector geometry. Header check is not full image decode. The palette is a reference, not a final texture. Text bounds are conservative rectangle checks, not visual glyph measurement. Future generated materials, animation frames and profile-specific assets require new contracts and PoC evidence.

## Isolated flavor regression
Run `python tools/check_flavor_isolation.py` after the normal validator and memory evaluator have populated `.aura-tools`. The CI step copies only the build inputs and shared tools to a temporary project. Generate a different WFF4 accent color from the existing template. Keep WFF2/3/5 on the common face. Clean-build all four APKs; verify the effective source, packaged XML bytes, memory and signatures. Change only the expected WFF4 source after building. Require the exact WFF4 mismatch failure and PASS for all three unaffected APKs. Restore the isolated source and recheck. The temporary APKs are not uploaded. Product resources remain unchanged. This checks build precedence and generator integration, not WFF4 motion or emulator rendering.

## Signature basic candidate
Run `python tools/generate_basic_face.py --write` and `--check`. Run `python tools/check_layout_reproduction.py` for independent process missing/stale rejection and repair. After the regular SDK/tool steps, run `python tools/check_basic_face_build.py`. It replaces only the common XML in a temporary project, builds four profiles and verifies official schema, APK contents, memory and signature. Candidate APKs are not distributed; the bootstrap preview inside the isolated APK is not a candidate preview. The CI uploads geometry and candidate XML as development evidence only. Product XML remains unchanged.
