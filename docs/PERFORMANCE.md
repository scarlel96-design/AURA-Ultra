# 성능 및 전력 예산
## 기준
| 지표 | 공식 기준(재확인 필요) | 프로젝트 목표 |
|---|---|---|
| 활성 WFF 메모리 | 100 MB | ≤70 MB |
| AOD WFF 메모리 | 10 MB | ≤7 MB |
| AOD 발광 픽셀 | ≤15% | ≤10% |
| 이미지 애니메이션 | 일반적으로 15fps 권장 | 15~30fps 후보 |
| 안정성 | 기기/정책에 따름 | 초기 8시간 오류·충돌 0 |

공식 문서의 단위 및 평가 방식을 WO-01에서 재확인한다. 목표는 실측 결과가 아니다. 전체 AOD 전환 시간은 시스템이 결정한다.

## 그래픽 예산
RGBA8888 단순 계산: width × height × 4 × frames. 480×480 30프레임은 약 27.65 MB(십진 단위). 160×160 30프레임은 약 3.07 MB. 실제 WFF evaluator의 결과가 우선한다.
원본은 고품질로 제작한다. 투명 영역을 잘라낸다. 움직이는 부분만 프레임으로 만든다. 정적 소재와 동적 하이라이트를 분리한다. 전체 화면 텍스처 복제를 피한다. 지원되는 벡터/그라데이션/마스크를 사용한다. 해상도별 리소스를 생성한다.

## 품질 프로필
Ultra: 최대 승인 소재·모션. Balanced: 대표 디자인 품질을 유지하며 장식 이벤트를 제한. Eco: 장식·센서 반사·입자 효과 우선 제거. AOD: 시간 중심, 검정 배경, 최소 발광, 장식 모션 없음.
Balanced 기본값은 제안이다. 사용자 선택과 실측으로 결정한다. WFF 기능별 프로필 적용 가능성을 검증한다.

## 측정
기기, 펌웨어, 밝기, AOD, 네트워크, 배터리 시작/종료, 화면 사용 패턴, 주변 온도, 테스트 시간, 기준 페이스를 기록한다.
동일 조건에서 기본 페이스와 AURA를 비교한다. 1시간 유휴/활성, 8시간 안정성, 이후 24시간 대표 사용 시험을 실시한다. 반복 시험의 편차를 보고한다. 백분율/시간과 가능 시 전력 측정값을 구분한다. 실기기 없이 배터리 수명을 추정해 확정하지 않는다.
