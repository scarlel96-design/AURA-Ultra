## Phase 게이트
Phase 1 (01~08): 환경·공식 규격·핵심 PoC. 미지원 기능은 대체안과 위험을 기록한다.
Phase 2 (09~16): Signature 소재 및 모션 품질 승인. 화려함을 축소하여 검증을 회피하지 않는다.
Phase 3 (17~23): 데이터·지능·복구 계약 검증.
Phase 4 (24~29): 8개 테마, 상세 UI, Companion, 설정 및 설치 관리. 조건부 기능의 범위를 확정한다.
Phase 5 (30~38): 최적화, 보안, 기기별 검증, 독립 비교, 정식 출시 게이트.
각 WO는 TEMPLATE.md에 따라 상세 작업지시서를 생성한다. 난이도, 포함/제외, 소유 파일, API, 명령, 테스트, 증거, 판정, 롤백을 확정한 뒤 시작한다. WO-02 상세 명세는 준비됐다. WO-03~38 상세 지시서는 미작성이다. 다음 작업 지시를 받으면 관련 상세 명세를 실행 전에 작성한다. 사용자 별도 승인 반복은 필요하지 않지만 필수 게이트는 유지한다.
