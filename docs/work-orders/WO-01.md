# WO-01 — 개발 환경 및 지원 기기 기준 확정
상태: PARTIAL. 초기 빌드 토대 확보 및 CI 검증 진행. 현재 상태는 ../STATUS.md를 참조한다.
요구사항: R-01, R-02, R-20, R-22, R-23, R-25.
선행 조건: 설계 기준선 문서 확인. 저장소 접근 및 개발 환경 확인.

## 목표 및 범위
공식 플랫폼 제약과 기기별 호환성, 설치 가능한 개발 환경, 검증 도구를 확정한다. 기본 워치 페이스 구현, 디자인 자산 제작, 전체 모듈 생성, 실제 배포는 제외한다.

## 작업
1. 현재 브랜치와 HEAD를 기록한다.
2. Windows/JDK/Android Studio/SDK/Gradle/ADB의 설치 및 버전을 확인한다.
3. WFF 2~5의 공식 버전별 지원 API와 스키마를 확인한다.
4. Watch7부터 최신 Galaxy Watch의 공식 모델·해상도·출시 OS를 확인한다.
5. 연결된 워치가 있으면 설치 OS, API level, 모델, 화면 크기, 빌드를 확인한다. 실제 지원 WFF 버전을 확인 가능한 방식으로 기록한다.
6. 연결된 워치가 없으면 NOT RUN을 기록한다. OS를 추정하지 않는다.
7. WFF Validator, Memory Footprint Evaluator, Optimizer의 공식 설치 및 실행 절차를 확인한다.
8. Wear OS 에뮬레이터와 Samsung Remote Test Lab의 사용 가능 범위를 확인한다.
9. 공식 메모리/AOD 품질 기준과 개인 APK 설치 및 Play 정책을 재확인한다.
10. Reference, Variant, Gyro, PartAnimatedImage, Watch Face Push 및 건강 API 지원표를 작성한다.
11. 호환성·근거 문서에 확인 결과를 반영한다.
12. 실제 증거를 첨부한다. 다음 단계 판정을 기록한다.
