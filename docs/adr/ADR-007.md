# ADR-007 — 패키지 및 배포 정책
상태: PROPOSED (정식 배포), ACCEPTED (기존 개발용 ID 유지). 관련 WO-02/29/38.
현재 개발용 debug ID는 다음 네 개다.

| 프로필 | Application ID | 최소 API |
|---|---|---:|
| wff2 | io.github.scarlel96.aura.watchface.wff2 | 34 |
| wff3 | io.github.scarlel96.aura.watchface.wff3 | 35 |
| wff4 | io.github.scarlel96.aura.watchface.wff4 | 36 |
| wff5 | io.github.scarlel96.aura.watchface.wff5 | 37 |

[프로필 계약](../../compatibility/profiles.json)과 [Gradle 설정](../../apps/watchface/build.gradle.kts)에 맞춰 flavor suffix를 유지한다. WFF5는 API37 개발 빌드에서 활성화했다. 설치 호환성은 별도 검증한다. 초기 WFF2~4 증거는 과거 기준선이다. 별도 Wear 실행 앱 및 phone 앱은 WFF와 분리한다. Data Layer 연결 앱의 패키지 및 서명 조건은 공식 API 검증 후 결정.
대안 A: 단일 낮은 WFF 버전의 배포 APK/AAB. 호환 범위 넓으나 상위 효과 제한.
대안 B: 별도 ID로 여러 WFF 배포. 독립 AAB와 설치/설정 관리 필요; 스토어 노출과 사용자 혼동 검토.
대안 C: 동일 ID에서 버전별 배포. Store 및 설치 경로, 버전 코드, 서명, 설정 이전의 공식 지원 확인 전 채택하지 않는다.
결정: 현재 개발용 패키지 ID 및 서명 정책 변경 없음. 정식 배포 전략과 ID는 WO-29 및 사용자 승인 후 확정한다. CI 임시 디버그 키는 업데이트 호환성 보장 없음. 실제 설치/이전 및 스토어 정책 증거 필요. 참고 Android WFF setup 및 App Bundle format ([SOURCES](../evidence/WO-01/SOURCES.md)).

개발용 ID 유지 결정은 정식 배포 ID, 라이선스, 서명 또는 스토어 정책 승인이 아니다. B-007은 OPEN이다. [현재 빌드 가이드](../BUILD_GUIDE.md)와 [API37 개발 증거](../evidence/GPT-02/REPORT-02.md)를 참조한다.
