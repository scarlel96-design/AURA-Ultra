# Signature 실기기 확인 및 승격 게이트
상태: NOT RUN. 사용자 승인 없이 기기를 변경하지 않는다. R06 정적 개발 후보의 조기 육안 검사이며 제품 출시 시험이 아니다.

## 1. 사전 조건
- 해당 SHA의 R06 전체 CI와 아티팩트 업로드 성공을 확인한다. aura-signature-material-development만 사용한다. bootstrap APK와 혼동하지 않는다.
- manifest.json의 sourceCommit과 선택 APK SHA-256을 확인한다. apksigner verify --verbose --print-certs로 서명을 확인한다. 공식 메모리 결과가 활성 73,400,320 B / AOD 7,340,032 B 이하인지 확인한다.
- 실제 모델, 설치 OS/API, 해상도 및 펌웨어를 기록한다. adb devices -l과 adb -s DEVICE shell getprop ro.build.version.sdk 및 wm size를 사용한다. 지원 WFF 버전은 별도 확인한다. API34/35/36/37의 해당 WFF2/3/4/5 후보 중 호환되는 하나를 선택한다. API 숫자만으로 호환성을 단정하지 않는다.
- 기존 페이스 선택과 동일 package ID 설치 여부를 기록한다. debug 인증서가 다르면 업데이트에 실패할 수 있다. 자동 삭제, 강제 다운그레이드, 기존 데이터 제거를 금지한다. 충돌하면 중단한다.
- 사용자 설치 승인을 얻은 후 adb -s DEVICE install APK를 사용한다. 기존 동일 패키지 업데이트는 인증서 확인 및 별도 승인 후에만 -r을 사용한다. 기기에서 직접 페이스를 선택한다.

## 2. 5~10분 조기 확인
| 항목 | 수용 조건 | 결과 |
|---|---|---|
| 설치 및 선택 | 설치 오류/빈 화면/크래시 없음 | NOT RUN |
| 시간/날짜 | 분 전환 및 12/24시 표시, 잘림 없음 | NOT RUN |
| Titanium | 60개 눈금, 원형 가장자리, 링의 불연속·겹침·깨짐 없음 | NOT RUN |
| Liquid Crystal | 패널 경계/반사/정보 대비, 눈부심·잘림 없음 | NOT RUN |
| AOD | 시간/날짜 유지, 소재 숨김, 깨우기/복귀 5회 이상 | NOT RUN |
| 밝기/가독성 | 실내 밝은 조건 및 어두운 조건에서 확인 | NOT RUN |
| 데이터 | 실제 표시 또는 누락 상태 확인, 0으로 대체하지 않음 | NOT RUN |

활성/AOD 화면 사진과 짧은 전환 영상을 수집한다. 민감한 건강값 및 위치 정보는 가린다. 캡처, 실제 손목 육안 평가, 소프트웨어 로그를 구분한다. 짧은 확인은 배터리·발열·장시간 안정성 측정이 아니다. 별도 P14/P15를 유지한다.

## 3. 승격 조건
개발 기본 페이스 승격: 동일 후보 SHA의 WFF2~5 공식 스키마/리소스/서명/메모리/회귀·무결성 성공 + 최소 1대 목표 워치의 설치 및 위 육안 항목 승인 + 사용자 명시적 승격 승인 + 실제 후보에 맞는 프리뷰와 단일 생성 경로 + 롤백 가능한 baseline 보존. 미검증 기기 호환성은 주장하지 않는다. 정식 제품 출시 기준은 QUALITY_GATES.md를 따른다. 하나라도 미충족이면 격리 후보와 Bootstrap을 유지한다. 승인 후 생성 도구 및 공통 검사기를 함께 전환하고 네 프로필 회귀를 실행한다. Bootstrap은 보관된 기준 fixture로 유지하며 두 제품 경로를 상시 관리하지 않는다.

기기 확인 기록: 후보 SHA/CI ID, APK SHA/서명, 모델/OS/해상도, 밝기/환경, 결과/결함/증거, 사용자 승인 여부, 기존 페이스 복원 여부. 설치 실패 시 기존 페이스를 유지한다. 테스트 후 사용자가 원래 페이스를 선택한다. 사용자 승인 없이 패키지를 삭제하지 않는다.
