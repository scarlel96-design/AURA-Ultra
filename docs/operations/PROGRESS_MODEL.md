## 실제 진행률
각 WO에 계획 작업량, 증거가 있는 완료 항목, 미완료 항목을 기록한다. 가중치가 승인되지 않은 항목은 임의 백분율 대신 개수 및 상태를 보고한다.
- WO 완료율 = 공식 GO WO 수 / 38. PARTIAL을 GO로 계산하지 않는다.
- GPT 묶음 완료율 = 실제 종료 기준 충족 묶음 수 / 12. 차단된 묶음은 PARTIAL.
- 검증 통과율 = PASS / 실행된 필수 시험 수. FAIL, SKIP, NOT RUN, PENDING을 각각 별도 표시한다. 미실행 시험을 분모에서 제외한 통과율만으로 출시 적합성을 판단하지 않는다.
- 작업량 추정은 확인 가능한 산출물과 남은 재작업을 기준으로 갱신한다. 파일 수, 줄 수, 커밋 수를 품질·완성도로 사용하지 않는다.

## 현재 기준선
정식 완료 WO 0/38. GPT 작업 묶음 완료 0/12. 설계 기준선과 초기 코드가 존재한다. 빌드 성공 증거는 있으나 CI 최종 판정 FAIL. 실제 제품 완성도는 산정 근거 부족으로 미확정. 최신 상태는 STATUS 및 실제 검증 증거에 따른다.

작업별 G0~G7 결과와 요구사항 추적표를 증거에 연결한다. 검증 도구의 실패 검출, 회귀 및 최종 SHA 대조가 필요한데 누락됐으면 해당 항목을 완료로 계산하지 않는다. 문서 운영 작업의 완료를 제품 WO 완료율에 합산하지 않는다.
