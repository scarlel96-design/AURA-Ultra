# AG-01 회차 03 — 증거 정확도 및 런타임 시험 준비
PRE-FLIGHT 수행. PR #2, 기준 74f04aab7abb4e846e3ca5fd798721bd732a1146. 기존 소유 경로만 변경. 독립 worktree. 기존 로그와 보고서 보존, 정정 및 새 실행 증거를 REPORT-03.md와 새 로그 경로에 기록한다.
1. AG01-AUD-01: 실제 sdkmanager --list 및 avdmanager list device stdout/stderr/종료 상태를 확보한다. 설치 필요 패키지, revision, device profile은 실제 출력과 대조한다. 하드코딩 목록은 추정 후보로 분리한다. 실패/미설치/도구 없음은 UNKNOWN 또는 NOT RUN. 임의 연결 장치가 있거나 이미지가 설치됐다는 사실만으로 Wear emulator READY를 선언하지 않는다. sdkmanager/avdmanager 부재, 오류, 빈 출력, 일반 폰 AVD와 Wear AVD 분리 시험을 작성한다.
2. AG01-AUD-02: 예상 거부 조건에 정확한 대상 XML 및 WFF 버전의 명시적 FAILED와 관련 스키마 오류를 요구한다. 도구 crash/timeout/잘못된 경로/버전/오류 문자열만으로 PASS 금지. duration 범위와 Reference 허용 부모 위반을 별도 negative fixture로 분리한다. 기존 52개 매트릭스 및 60 validator subtests를 유지하고 추가 회귀 시험을 실행한다.
3. AG01-AUD-03: 잘못된 날짜, compatibility/profiles.json 경로, 환경 수치와 G6 의미를 원본 증거로 정정한다. 보존된 이전 결과를 수정하지 않는다. AOD ablation 결론은 평가기 조건 범위로 제한하고 font fallback 경고 및 실기기 NOT RUN을 기록한다.
4. 런타임 시험은 실제 Wear AVD만 대상으로 한다. 기존 폰 AVD와 실제 워치는 변경하지 않는다. 명시적인 emulator serial(-s)과 실제 워치 페이스 선택 확인, AOD 상태 확인 및 전환 녹화 절차를 작성한다. --force로 기존 AVD를 덮어쓰지 않는다. 신규 SDK 다운로드/AVD 생성은 사용자 명시 승인 후에만 수행한다. 승인 시 WFF4/5부터 1개씩 시험하고 필요 시 2/3으로 확장한다. 승인 전에는 환경 조사 및 무다운로드 시험만 수행한다.
5. 원본 6 APK/4 ablation 증거는 유지한다. 변경한 검사기 관련 회귀를 실제 실행한다. 실패를 숨기지 않는다. PR #2 업데이트, REPORT-03, 변경 SHA/실행 로그/미실시 항목 제출. main 직접 병합 금지. 제품 출시 NO-GO 유지.
